# Тест-дизайн СМП: Authorization и Card Management

## Классы эквивалентности

### Authorization

| Поле | Позитивные классы                                      | Негативные классы                                     |
|---|--------------------------------------------------------|-------------------------------------------------------|
| `card_exists` | Карта найдена                                          | Карта не найдена                                      |
| `card_status` | `ACTIVE`                                               | `INACTIVE`, `BLOCKED`, `EXPIRED`                      |
| `expiryDate` | Текущий месяц, будущий месяц                           | Прошлый месяц                                         |
| `dailyLimit` | Потрачено за день + сумма покупки <= дневного лимита   | Потрачено за день + сумма покупки > дневного лимита   |
| `monthlyLimit` | Потрачено за месяц + сумма покупки <= месячного лимита | Потрачено за месяц + сумма покупки > месячного лимита |
| `availableBalance` | Баланс >= суммы покупки                                | Баланс < суммы покупки                                |

### Card Management

| Поле или операция | Позитивные классы | Негативные классы |
|---|---|---|
| Получение карты по PAN | Карта существует | Карта не найдена , карта удалена |
| Статус карты в списке | `ACTIVE`, `INACTIVE`, `BLOCKED`, `EXPIRED` | `DELETED`  - карта не попадает в список |
| Фильтр списка по `status` | Карта соответствует выбранному статусу | Карта не соответствует выбранному статусу |
| Фильтр списка по `bin` | BIN карты совпадает с фильтром | BIN карты не совпадает с фильтром |
| Создание карты | Поля заполнены, BIN содержит 6 цифр | Обязательное поле не заполнено , BIN неверной длины |
| Сгенерированный PAN | 16 цифр, проходит проверку Луна | PAN другой длины или не проходит проверку Луна |
| Сгенерированный `expiryDate` | 4 цифры в формате MMYY, срок  - текущая дата + 3 года | Другая длина или неверный формат |
| Изменение карты через PATCH | Переданы статус, лимит или баланс | Передано поле, которое нельзя изменить |
| Генерация карт | `count` больше 0, список BIN не пуст | `count` равен 0 или меньше , список BIN пуст |
| Резервирование средств | Суммы на балансе хватает | Сумма больше баланса |

## Граничные значения

### Authorization

| Поле | ON | OFF | Ожидаемый результат |
|---|---|---|---|
| `dailyLimit` | `daily_amount + amount = dailyLimit` | `daily_amount + amount = dailyLimit - 1` или `dailyLimit + 1` | Ниже или равно лимиту  - одобрено (`00`); выше  - отказ (`61`) |
| `monthlyLimit` | `monthly_amount + amount = monthlyLimit` | `monthly_amount + amount = monthlyLimit - 1` или `monthlyLimit + 1` | Ниже или равно лимиту  - одобрено (`00`); выше  - отказ |
| `availableBalance` | `amount = availableBalance` | `amount = availableBalance - 1` или `availableBalance + 1` | Денег хватает  - одобрено (`00`); не хватает  - отказ (`51`) |
| `expiryDate` (MMYY) | `expiryDate = текущий месяц` | `expiryDate = предыдущий месяц` или `следующий месяц` | Текущий и следующий месяц  - карта действительна; предыдущий  - отказ (`54`) |

### Card Management

| Поле | ON | OFF | Ожидаемый результат |
|---|---|---|---|
| Длина `pan` | `length(pan) = 16` | `length(pan) = 15` или `17` | Созданный PAN содержит 16 цифр и проходит проверку Луна |
| Длина `bin` | `length(bin) = 6` | `length(bin) = 5` или `7` | При BIN из 6 цифр создаётся PAN из 16 цифр |
| Формат `expiryDate` | `length(expiryDate) = 4` | `length(expiryDate) = 3` или `5` | Созданный срок состоит из 4 цифр в формате MMYY |
| `availableBalance` при резервировании | `amount = availableBalance` | `amount = availableBalance - 1` или `availableBalance + 1` | Денег хватает  - баланс уменьшается на сумму; поведение при нехватке денег в ТЗ не описано |

## Таблица решений Authorization

Проверки выполняются по порядку. Для каждой строки предыдущие условия считаются выполненными.

| Условие | Решение | Код или причина |
|---|---|---|
| CMS недоступен | DECLINED | `05`, `ISSUER_TIMEOUT` |
| Карта не найдена | DECLINED | `14` |
| Статус `INACTIVE` | DECLINED | `CARD_INACTIVE` |
| Статус `BLOCKED` | DECLINED | `CARD_BLOCKED` |
| Статус `EXPIRED` или срок истёк | DECLINED | `54` |
| Превышен дневной лимит | DECLINED | `61` |
| Превышен месячный лимит | DECLINED | Код в ТЗ не указан |
| Не хватает баланса | DECLINED | `51` |
| Все проверки пройдены | APPROVED | `00`, сумма зарезервирована |

Если Bin Lookup недоступен, используется `issuerId` от Switch, а проверка продолжается.

## Попарное тестирование

Для Authorization созданы `pict/model.txt` и `pict/cases.txt`. Для Card Management  - `pict/model-card-management.txt` и `pict/cases-card-management.txt`. В каждой модели шесть параметров. В Card Management каждая строка набора задаёт сочетание для одной операции; `na` означает, что параметр для неё не нужен.
